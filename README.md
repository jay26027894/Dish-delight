Dish Delight 🍽️
Technologies Used: HTML, CSS, JavaScript


Description:
Dish Delight is an interactive recipe website designed to provide a seamless cooking experience. It features a curated collection of 48+ dishes, categorized into Breakfast, Lunch, Hi-tea, and Dinner, making it easy for users to explore and find their favorite recipes.

Key Features:
✅ Search Functionality – Quickly filter and find dishes based on keywords.
✅ Interactive Recipe Cards – Clickable cards display detailed dish descriptions and ingredients in modals.
✅ Mobile-Responsive Design – Ensures smooth browsing on desktops, tablets, and smartphones.
✅ Engaging UI/UX – Clean layout with intuitive navigation for an enhanced user experience.
✅ Map Integration – Potential for future expansion, such as locating nearby ingredient sources or restaurants.

This project highlights my skills in front-end development, UI/UX design, and interactive web elements. I developed it using HTML, CSS, and JavaScript, focusing on responsiveness and user engagement. Future enhancements may include user-authored recipes, personalized recommendations, and API-based ingredient search.

Dish Delight is a testament to my passion for web development and creating user-centric digital experiences.
